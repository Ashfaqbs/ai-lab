Masking enabled
Turn off to pause InfraMask everywhere without removing it.

What to mask

Credentials & secrets
Passwords, API keys, tokens, JWTs, private keys, database connection strings.
Infrastructure identifiers
IP addresses, internal hostnames, Kafka bootstrap servers, URLs.
PII & retail-sensitive data
Email addresses, phone numbers, SSNs, credit/debit card numbers (checksum-validated).

Supported sites

  • chatgpt.com / chat.openai.com
  • claude.ai
  • gemini.google.com
InfraMask only runs on these sites by design - it is not injected anywhere else. Adding a new site means adding a selector entry in src/site-adapters.js.
InfraMask v - masking happens entirely in your browser; nothing is sent anywhere.
